## Open questions

- **0.23.0 republishes byte-identical crates.** `crates/`, `Cargo.toml` and
  `Cargo.lock` have no change since v0.22.0 — this slice is entirely site+docs.
  0.13.1 set the opposite precedent ("that work alone left the Rust tree
  byte-identical to 0.13.0 and so carried no bump"). Cutting it was a
  deliberate call, recorded in the release notes; the alternative was letting
  it ride with the next crate change. Reversible only *before* the tag push.
- `CLAUDE.md` names a gate `docs_match_code::the_website_copies_match_the_docs`
  that **does not exist**. The real file has 5 tests, none covering
  `site/src/lib/content/` — which is generated by `copy-content.mjs` and
  gitignored, so it cannot drift. The checklist line should be corrected.
- Does sensei's 43,737 count occurrences or unique pairs? Until settled, a
  residual difference is not a defect.
